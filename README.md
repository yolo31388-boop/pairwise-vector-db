# 游戏内向量数据库与相似度检索系统

## 项目描述

游戏内向量数据库与相似度检索系统的bug修复项目。核心模块 `ai/vector_db.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 向量插入只存原始数据没有建索引
- 相似度检索用欧氏距离不是余弦相似度
- ANN索引完全没做10万向量检索要10秒
- 嵌入完全没做文本不能转向量
- 聚类完全没做不能对向量分组

## 运行测试

```bash
python -m pytest tests/test_vector_db.py -q
```

修复目标：所有 15 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
